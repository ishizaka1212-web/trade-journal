売買ジャーナル（Ver.46から派生した独立アプリ）

index.html をブラウザで開くか、GitHubの新しいリポジトリに配置してVercelで公開してください。
既存のVer.46とは別アプリです。Ver.46のデータを自動では読み込みません。

機能:
- 買い・売りの約定日、銘柄コード・名称、株数、約定単価、理由、感情、メモ
- 取引金額の自動計算
- 取引履歴の編集・削除・検索
- 銘柄別の買付株数・売却株数・保有残高と累計約定金額
- 売却超過チェック（同一日内は登録ID順）
- CSVエクスポート・インポート
- 端末内のlocalStorageに保存（端末間同期なし）

注意:
- 株式分割、移管、手数料、税金、信用取引、実現損益、平均取得単価は未対応です。
- CSVを定期的にバックアップしてください。
